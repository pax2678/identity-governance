# app/api/

API routes for the IGA Core Data Model application.

## Route Structure

API routes will be implemented in phases based on user stories:

- **Phase 3 (US1)**: Identity and account management endpoints
- **Phase 4 (US2)**: Entitlement catalog endpoints
- **Phase 5 (US3)**: Grant discovery endpoints
- **Phase 6 (US4)**: Access request endpoints
- **Phase 7 (US5)**: Provisioning endpoints
- **Phase 8 (US6)**: Certification campaign endpoints

See [contracts/](../../specs/001-iga-core-data-model/contracts/) for API specifications.
