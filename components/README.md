# components/

React components for the IGA Core Data Model application.

## Directory Structure

- **ui/** - shadcn/ui component library (installed via npx shadcn-ui add)
- Other subdirectories for feature-specific components will be added during implementation

## shadcn/ui Components

Install components as needed using:
```bash
npx shadcn-ui@latest add [component-name]
```

Phase 2 (T036) will install: table, card, badge, button, input, form, dialog
