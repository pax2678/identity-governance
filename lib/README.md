# lib/

Business logic and shared utilities for the IGA Core Data Model application.

## Directory Structure

- **services/** - Business logic services (identity, account, entitlement, etc.)
- **connectors/** - Target system connectors (LDAP, SCIM, cloud IAM)
- **models/** - TypeScript domain models with Zod validation
- **db/** - Database client and utilities
- **auth/** - NextAuth.js authentication configuration
- **utils/** - Shared utility functions

These directories will be populated in Phase 2 (Foundational) tasks T022-T035.
